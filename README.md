# 🖋️ ویراستار پیشرفته متن فارسی (Persian Virastar)

یک ابزار تحت وب فوق‌العاده مدرن، سریع و با کارایی بالا برای **ویراستاری، نرمال‌سازی، پاکسازی و اصلاح نگارشی متون زبان فارسی**. این پروژه با استفاده از معماری نوین فرانت‌اند توسعه یافته و دارای ابزارهای تحلیل پیشرفته متون، شاخص خوانایی اختصاصی زبان فارسی و قابلیت‌های جانبی قدرتمند است.

---

## ✨ ویژگی‌های برجسته کلیدی

- **🔍 اصلاح پیشرفته نیم‌فاصله‌ها:** قرار دادن هوشمند و اتوماتیک نیم‌فاصله برای پیشوندها (مانند می‌، بی‌) و پسوندها (مانند ها، تر، ترین، م، ت، ش، مان، تان، شان) و نشانه‌های جمع و مضاف.
- **✍️ تنظیم و تصحیح نشانه‌گذاری (Typography):** اصلاح فاصله قبل و بعد از علائم نگارشی (نقطه، کاما، علامت سوال، علامت تعجب، دو نقطه، پرانتزها، گیومه و...).
- **🔢 نرمال‌سازی اعداد و علائم:** تبدیل اعداد انگلیسی و عربی به اعداد استاندارد فارسی و اصلاح کلمات عربی (ک و ی عربی به فارسی).
- **📊 تحلیل منسجم متن و شاخص خوانایی فارسی:**
  - محاسبه بلادرنگ تعداد کلمات، جملات و پاراگراف‌ها.
  - سنجش اتوماتیک سختی متن بر اساس فرمول‌های بومی خوانایی فارسی (آسان، متوسط، دشوار).
  - محاسبه میانگین طول جملات و تخمین دقیق زمان مطالعه.
  - نمودار مقایسه‌ای کوچک و بهینه برای ارزیابی حجم ورودی و خروجی.
- **✨ دستیار بازنویس و ویراستار هوشمند (Gemini AI):** امکان ویرایش عمیق املایی/دستوری، ساده‌سازی متون پیچیده، خلاصه کردن و تغییر لحن متن (به لحن رسمی، صمیمی، علمی، مطبوعاتی و...) با استفاده از مدل پیشرفته Gemini.
- **🔄 مقایسه‌گر زنده تغییرات (Diff Viewer):** نمایش کاراکتر به کاراکتر تغییرات ایجاد شده در متن به صورت هایلایت‌شده و تفکیک رنگ بسیار جذاب.
- **🔑 قفل امنیتی و اشتراک‌گذاری:** امکان ایجاد لینک اشتراک‌گذاری رمزگذاری‌شده همراه با تاریخ انقضا و کلمه عبور برای انتقال امن متون.
- **📂 بارگذاری و خروجی فایل:** پشتیبانی از کشیدن و رها کردن (Drag and Drop) فایل‌های متنی (`.txt`) و دریافت خروجی با فرمت‌های مختلف.
- **🎨 طراحی بصری بهینه و ارگونومیک (UI/UX):** پوسته تیره و روشن هماهنگ، فونت زیبای **وزیرمتن**، استفاده از سیستم انیمیشن‌های نرم و طراحی متقارن بدون شلوغی‌های غیرضروری.

## 🛠️ تکنولوژی‌های مورد استفاده (Tech Stack)

- **فریم‌ورک اصلی:** [React 18](https://reactjs.org/) با ساختار تایپ‌سیف و مستحکم **TypeScript**
- **سیستم ساخت سریع:** [Vite](https://vitejs.dev/) برای بارگذاری آنی فرانت‌اند و غیرفعال‌سازی HMR مخل کارکرد
- **فریم‌ورک استایل‌دهی:** [Tailwind CSS](https://tailwindcss.com/) برای طراحی کاملاً واکنش‌گرا و سفارشی با رنگ‌های اشباع‌شده ملایم بومی
- **سیستم نمودارها:** [Recharts](https://recharts.org/) برای تصویرسازی داده‌های آماری متن در قالب ساختار فشرده و مدرن
- **کتابخانه آیکون‌ها:** [Lucide React](https://lucide.dev/)
- **دستیار هوشمند:** SDK رسمی `@google/genai` برای اتصال امن و سرور-ساید به مدل‌های هوش مصنوعی Gemini

## 🚀 نحوه نصب و راه‌اندازی پروژه

پروژه به صورت کاملاً خودکفا و فول‌استک (یکپارچه با سرور Express جهت مدیریت امن کلیدهای API) راه‌اندازی می‌شود.

### ۱. نصب وابستگی‌ها
ابتدا ترمینال را باز کرده و دستور زیر را اجرا کنید:
```bash
npm install
```

### ۲. تنظیم متغیرهای محیطی
یک فایل به نام `.env` در ریشه پروژه ایجاد کرده و کلیدهای مورد نیاز را قرار دهید (مانند نمونه موجود در `.env.example`):
```env
GEMINI_API_KEY=your_gemini_api_key_here
```

### ۳. اجرای برنامه در محیط توسعه (Local Development)
برای راه‌اندازی سرور توسعه Express و Vite در پورت ۳۰۰۰:
```bash
npm run dev
```

### ۴. ساخت نسخه نهایی و اجرا در محیط عملیاتی (Production Build)
برای ایجاد باندل فشرده و بهینه‌سازی‌شده برای سئو:
```bash
npm run build
npm start
```

## 📂 ساختار کدهای پروژه

```text
├── src/
│   ├── components/            # کامپوننت‌های بهینه و مجزای رابط کاربری
│   │   ├── Header.tsx         # سربرگ و کنترل‌های اصلی قالب و میانبرها
│   │   ├── VirastarEditor.tsx # بدنه اصلی ویرایشگر دو پنله زنده
│   │   ├── StatsChartWidget.ts # ماژول بهینه‌سازی شده تحلیل متن و خوانایی
│   │   ├── AiAssistantModal.ts # دستیار بازنویسی و تغییر لحن هوشمند
│   │   └── ...
│   ├── data/                  # داده‌های ثابت و متن‌های نمونه پیش‌فرض
│   ├── lib/                   # هسته پردازشگر و موتور ویراستاری بومی
│   │   ├── virastarEngine.ts  # موتور بهینه اصلاح نیم‌فاصله و علائم با Regex
│   │   └── aiService.ts       # پردازشگر ارتباط با API هوشمند سرور-ساید
│   ├── types.ts               # تعاریف تایپ‌ها و اینترفیس‌های منسجم
│   ├── main.tsx               # نقطه ورود اصلی برنامه
│   └── index.css              # استایل‌های سراسری مبتنی بر Tailwind
├── server.ts                  # سرور Express میانی برای پروکسی امن درخواست‌ها
├── package.json               # مدیریت اسکریپت‌ها و وابستگی‌های پروژه
└── index.html                 # ساختار قالب HTML بهینه‌سازی شده برای سئو (SEO)
```

## 📈 بهینه‌سازی سئو (SEO & Performance)

این پروژه از نظر ساختاری برای موتورهای جستجو کاملاً بهینه‌سازی شده است:
- استفاده از تگ‌های استاندارد **Open Graph** و **Twitter Cards** برای اشتراک‌گذاری بهینه در شبکه‌های اجتماعی.
- افزودن ساختار داده نشاندار **Schema.org (JSON-LD)** در قالب `WebApplication` برای درک بهتر موتورهای جستجو از برنامه.
- سازگاری کامل با استانداردهای دسترسی‌پذیری و بارگذاری فونت وزیرمتن بومی با بهینه‌ترین سرعت.
